# leveluper.com

Static site built with [Astro](https://astro.build).

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # outputs dist/
```

## Editing content

- **Projects:** one Markdown file per project in `src/content/projects/` (copy `_template.md`).
- **Everything else:** `src/data/site.ts`.
